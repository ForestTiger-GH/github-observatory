# Results — Epoch 001 Research

This directory contains durable Results of commissioned Research or related development Work performed during Epoch 001.

A Result is a bounded Work outcome. It is not automatically current repository truth, a schema change, a Product Decision, or a Commission for successor Work.

A material Result should preserve enough context for valid reuse: Subject, relevant Baseline or source universe, scope, findings or established outcome, evidence/provenance, uncertainties and limits, and any material residue.

Later Work may use a Result as input, but changes to current repository owners require their own Commission, Authority, and acceptance path.
