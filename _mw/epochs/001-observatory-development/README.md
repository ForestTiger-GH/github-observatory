# Epoch 001 — Observatory Development

## Status

**ACTIVE / RESEARCH AND DEVELOPMENT**

## Purpose

Provide the first bounded Development Epoch for researching and developing GitHub Observatory while preserving its current repository contracts unless a separately commissioned Work changes them.

The epoch may investigate the Observatory's collection model, GitHub API constraints, data quality, metric semantics, automation, reliability, presentation, derived analysis, visualization, operational behavior, and other justified concerns.

This scope is a research and development horizon, not pre-authorization to change the current collector, schema, stored data, or repository purpose.

## Current routes

Research:

`research/`

Durable Research and related development Results:

`research/results/`

## Current commitments

The epoch currently commits only to:

1. preserve a clear boundary between Research/Work history and current repository truth;
2. keep substantive Results durable and recoverable;
3. preserve source identity, Baselines, evidence, uncertainty, and limits where material;
4. avoid speculative workspace structure;
5. route any proposed Product, schema, collector, or operational change through its proper current owner and Authority.

## Closure

Epoch closure is not pre-written. A large Research corpus, an empty queue, or a single completed study does not by itself close the epoch.
