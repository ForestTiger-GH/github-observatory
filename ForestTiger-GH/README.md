# Generated repository observations

This directory is managed by the Observatory workflows.

`repositories.csv`, `_collection/`, and one directory per automatically discovered `ForestTiger-GH` repository are generated by the collector. Do not manually maintain a repository list here; new repositories are discovered from GitHub on every run.

Daily data uses closed UTC calendar days. The scheduled collector runs at 01:00 UTC and attributes normal snapshots to the UTC day that ended one hour earlier. Branch/ref names are not stored as observation dimensions.
